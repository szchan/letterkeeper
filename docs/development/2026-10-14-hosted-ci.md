# 2026-10-14：公开仓库与远程 CI

用户授权建立公开 GitHub [szchan/letterkeeper](https://github.com/szchan/letterkeeper)、推送开发分支，将重型构建/测试迁移到远程。用户明确允许既有 Git 作者个人邮箱保留在公开历史中。主代理负责公开前数据审查、仓库创建与集成；本次授权不包括发行版或真实账户测试。

## 实施范围

- 主代理分配 CI 和文档子任务，各自独立分支/worktree、限定可改文件；主代理审查后集成，不让子代理直接改 main。
- CI 完整门禁保留 workspace 测试、fmt/Clippy、PTY、工作区、隐私 HTTP/DNS 和实际 Codex 路径；独立 TDD evidence 以精确 SHA、crate、test、RED/GREEN dispatch，真实失败保留为失败，不自动取消。
- 更新 README、AGENTS、WORKFLOW 与 [ADR 0004](../decisions/0004-hosted-ci.md)，明确本机不运行重型 Cargo、当前项目应关闭编辑器自动检查（本轮未修改编辑器配置）、公开合成日志/产物与远程性能新基线。
- 公开空仓库首次 main 推送用于 bootstrap workflow，随后设置并复核 main 保护；初次 CI 与保护结果未完成时仍记为待验证，后续开发走 PR。
- 任务分支第一次推送立即开 draft PR；main push/PR 更新自动跑 CI，PR 前手动 dispatch。集成版本需新一轮完整 `ci-gate`，main 保护需实际设置并复核。

普通 PR 的上表 SHA 是任务分支 head；Actions checkout 另测试其当时合并 revision。精确 Rust TDD workflow 则单独 checkout 输入 SHA 并核对 HEAD。完整门禁保留 210 项已注册 Rust 测试（其中子进程/benchmark helpers 按既有说明计数）、fmt/Clippy、三项实际 PTY/展示脚本和公共 Codex app-server。新增轻量编排 11 项及 Codex readiness 8 项；本机没有运行 Rust 构建、check、测试、Clippy 或性能负载。

Ubuntu 24.04.5 runner 使用 Rust 1.99.0、bubblewrap 0.9.0。最初把 `/lib64` 指向 `usr/lib` 的 Arch 假设导致 worker 无法启动，改为只读实际库目录。移除过宽 AppArmor fallback 后，真实预检因 `RTM_NEWADDR: Operation not permitted` 失败；仅为临时 runner 的系统 `/usr/bin/bwrap` 替换同名 namespace 例外，保留其他 profile 与全局 sysctl，再验证嵌套 namespace、无 home、零有效 capabilities 和隔离网络。本机未修改 AppArmor。

环境探针先注入合成 auth 变量并取得 RED，再 `--clearenv`。bubblewrap 明确保留 PWD，故将其固定为 `/tmp` 并验证确切值；其余仅允许 HOME/PATH/LANG，真实 auth 值不进入或输出。PTY 修复取得 controlling terminal、观察编辑和完整缩窗帧后再发键；没有删除 dirty/退出/终端恢复断言，也没有声称已修复应用任意同时缩窗/输入的行为。Codex 只等待官方 schema 的正常启动状态，终止状态立即失败；旧日志没有状态值，不把异步启动推测写成确证。详见[Ubuntu](../testing/ubuntu-sandbox.md)、[终端](../testing/hosted-terminal.md)及[Codex](../testing/codex-hosted.md)。

一轮 GREEN dispatch 手工抄录了错误 SHA，一轮进入 Cargo 前被环境拒绝，均未当作业务 RED/GREEN。旧手动构建在源码包补齐前被取消，未记作成功；普通过期 CI 可取消，TDD evidence 不自动取消。初始 CI bootstrap 与修复提交保留原失败历史。

## 分支保护、产物和后续流程

main 保护已通过 GitHub API 配置并复核：PR 必需、`ci-gate` strict=true、enforce_admins=true、线性历史、禁止强推/删除、会话需解决；不要求其他人的批准数（0），代码由主代理审查。Actions 默认 token 只读，禁止自动批准 PR；各 workflow 显式只读权限。终端子代理 PR #2 在完整检查通过后合入集成分支；其他最终变更按 PR 与最新门禁进入 main。

release 产物 ID `11880208853`，压缩大小 64,558,996 字节，保留 7 天。下载后 7 个 payload 与 manifest 的 8 个校验和均通过；二进制没有在本机运行。包中有精确提交项目源码、Cargo vendor 依赖源码/原始署名与许可证、重建说明和 SHA-256，不构成法律认证或跨环境逐字节重建保证。合成性能及限制见[托管样本](../testing/hosted-performance.md)，不与 Arch 数据混比。

模型分工：CI 配置/安全边界使用 GPT-6.1-Sol high；文档、PTY 和 Codex 验证修复使用 GPT-6.1-Sol medium；公开历史审计、静态复核与性能文档使用 GPT-6-Luna high。每项有独立分支/worktree、可改文件限制；主代理协调接口、只集成已审查提交。没有让全部任务使用最高成本模型。依赖只缓存 registry/git，不复用跨 worktree target。

后续操作以 [WORKFLOW](../WORKFLOW.md) 和 [CI 验证](../testing/ci.md)为准：任务分支首次推送立即开 draft PR，保留真实 RED run 后实现 GREEN，集成和 main 的新版本再验证。公开授权覆盖该仓库开发推送；发行版及真实服务操作继续独立授权。

真实 Gmail/系统凭据库仍是独立关卡，未据此扩大授权。未使用真实邮箱、外发邮件或上传本机私有配置。
