# ADR 0003：TUI 与 Agent 人工审批工作流

日期：2026-10-13。状态：受控实施与验证已完成；真实服务关卡未授权/验收。用户确认内置编辑器、人工审批闭环，真实 Gmail/Secret Service 是独立授权验收关卡。基线 539fa3f、170 项测试；不将受控验证写成全部 P0 完成。

新增 `HumanWorkspace` 类型化能力供 CLI/TUI 使用，独立于模型的 Host；MCP 保留 14 个工具，无批准/文件路径/配置入口。共用现有 Store、身份检查、版本冲突、单次批准、发送进程锁与不可变 MIME。批准重新加载摘要，要求完整输入摘要，有效 300 秒；批准不自动发送。SQLite schema 2 和旧摘要兼容。

本地草稿/提交各分页 50 项。TUI 内置 To/Cc/Bcc、主题、正文编辑，发件账户固定、回复线程头不可自由编辑。正文 1 MiB，撤销最多 20 次，危险粘贴控制字符拒绝。新增 tui-textarea =0.7.0（MIT，https://github.com/rhysd/tui-textarea；兼容现有 Ratatui 0.29/Crossterm 0.28）。上游已有独立 fork，兼容版本的维护风险需明确，不在本阶段升级整个终端框架；仅启用 crossterm，不启用搜索/序列化/其他后端。依赖清单由集成分支最终 metadata 更新。

网络与本地草稿各一个后台 worker，有界队列。浏览取消仅丢弃显示，副作用的结果要保留并可从持久化记录查询；退出不得宣称正在发送已取消。未保存退出提供保存/放弃/继续，冲突保留编辑内容并允许另存新草稿。

审批视图完整可滚动，显示精确收件人/正文/线程头和附件字节 SHA-256，危险字符可逆转义，不使用 inert_text 有损截断作为批准依据。附件仅显式文件导入/保存、512 KiB、NOFOLLOW，不预览或执行。既有 Sent/Drafts 同步保持显式。

快捷键：浏览 c 新建、d 草稿、R/A/F 回复/全部回复/转发，s 提交记录；编辑 Tab 切换、Ctrl+S 保存；F6 审阅、F8 输入摘要批准、F9 显式发送。编辑中的 q 是普通字符；Esc 未保存退出需决策，Ctrl+Q 退出也检查未保存内容。

验证要求：保留 170 回归，新增成功/拒绝/边界/状态/并发；真实 PTY 四尺寸、恶意粘贴/宽字符/完整批准/发送/termios；HTTP/DNS canary 包括编辑与审阅；标准 MCP 客户端展示验证。性能采用 release、固定 1k/10k 邮箱、32 KiB 常用正文及 2 MiB 边界，测进程树 RSS/PSS/CPU 和输入响应；p95 输入 ≤100ms、空闲 CPU ≤单核1%。失败先定位不降低门槛。

真实凭据库用专用合成条目且另行授权；Gmail 读操作和发送/草稿写操作分别列明确账户/文件夹/收件人的清单再授权。凭据由用户本机输入；不向聊天或仓库提交。未授权时完成可独立进行的受控开发，明确保留关卡未验收。
