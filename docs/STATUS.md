## 已知技术限制

- 正文 worker 依赖 Linux bubblewrap 和当前 Arch 系统路径。库 API 自身不建立进程沙箱；应用必须通过 worker，不能直接用解析库处理生产输入后声称同等隔离。
- SQLite 的路径检查和打开不是针对同 UID 任意代码攻击的完整文件系统防护；祖先路径/TOCTOU 加固及独立 OS 身份在生产账户阶段继续评估。
- 发送不确定后不会自动重试；核心有显式恢复接口，但应用尚无能确认其他发送进程已退出的恢复 UI。重新打开数据库不会擅自覆盖活跃提交。
- CLI `read` JSON 的内部链接目标仍存在；只能作为数据使用。默认 TUI/MCP 采取有损去活化格式，不能用其截断视图代替完整人工发送审阅。
- 本轮没有进行真实账户网络、外发邮件、删除或账户状态修改，也未推送/发布。
